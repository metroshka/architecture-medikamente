# Задание 1. Анализ безопасности системы

## Цель задания

Я проследил, какие конфиденциальные данные проходят через подразделения «Медикаменте» и где при их обработке возникают риски. Для каждого процесса я предложил меры защиты, а для документов и выгрузок — правила назначения и проверки меток.

## Как читать диаграммы

В `dfd/as-is` показаны текущие процессы из описания клиники. Сплошные стрелки обозначают подтвержденные связи, пунктирные — допущения, которые еще нужно проверить. Коды P01–P08 обозначают процессы, D01–D12 — категории данных.

В `dfd/to-be` верхняя часть каждой схемы повторяет исходный поток, а внизу собраны предлагаемые меры защиты. Номер карточки связывает ее с операцией наверху. Например, для операции P01.2 «Сохранить файл пациента» в карточке P01.2 указано, где хранить медицинский скан и кому открыть доступ. Карточки без номера относятся к процессу в целом. Архитектуру новой платформы я рассматриваю отдельно в [задании 2](../Task2/README.md).
