# Архитектура «Медикаменте»

Проектная работа 10-го спринта курса «Архитектор программного обеспечения». Александр Ромашков.

Клиника ведет расписание и медкарты на общем диске, платежи и складской учет — в 1С. Перед открытием филиалов ей нужно защитить данные пациентов и подготовиться к пятикратному росту их объема. Первый этап проекта — самостоятельная запись на прием через портал. Через год к нему добавятся мобильное приложение, лабораторный обмен и аналитика. [Исходная схема клиники](https://code.s3.yandex.net/software-architect/project10-landscape.drawio.xml)

## Как открыть диаграммы

В Task1 обе схемы P01 сохранены в формате `.drawio` и открываются в draw.io. У остальных схем Task1 и у всех схем Task2 расширение `.drawio.svg`. Их можно посмотреть на GitHub и открыть в draw.io для редактирования. У диаграммы Исикавы два файла — [SVG для просмотра](Task4/ishikawa.svg) и [исходник draw.io](Task4/ishikawa.drawio).

## Порядок просмотра

Начните с реестра и пары схем одного процесса в Task1. Затем в Task2 сравните MVP с годовым состоянием и откройте детализацию аналитики. В Task3 можно проследить, как защищается та же категория данных, а в Task4 — какие риски возникают при переходе.
