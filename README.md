# Архитектура «Медикаменте»

Проектная работа 10-го спринта курса «Архитектор программного обеспечения».

Автор: Александр Ромашков.

## Задача проекта

Спроектировать развитие информационных систем медицинской компании «Медикаменте»: автоматизацию работы с данными, защиту конфиденциальной информации, интеграцию с лабораторией и подготовку данных для аналитики.

Решение должно учитывать открытие филиалов, расширение команды и пятикратный рост объёма данных. Ближайший этап — MVP для самостоятельной записи пациента на приём и работы ресепшена. Целевое состояние включает мобильное приложение, уведомления, разграничение доступа, аудит и контроль обработки чувствительных данных.

## Оформление решений

- Текстовые пояснения и таблицы — Markdown.
- Редактируемые диаграммы — draw.io. Для просмотра в GitHub при необходимости добавляются экспорты SVG или PNG.
- Существующее состояние, предлагаемые изменения и допущения обозначаются отдельно.
- На диаграммах потоков данных указываются источники и получатели, процессы, хранилища, направления передачи и состав данных.
- Выбор архитектурных компонентов и средств защиты обосновывается требованиями проекта.

## Работа с Git

- `main` содержит начальную структуру проекта.
- `solution` предназначена для решений всех четырёх заданий.
- Сообщения коммитов и описание pull request оформляются на русском языке.
- Для проверки создаётся один pull request из `solution` в `main`. На ревью отправляется ссылка на этот pull request.
- До завершения проверки pull request остаётся открытым. После отправки работы изменения вносятся по замечаниям ревьюера.
